# 文明史资料获取策略

## 基本原则

本项目只使用合法来源建立资料库。

可以做：

1. 下载出版社、机构、大学、博物馆、UNESCO 等官方明确开放的 PDF、网页和数据。
2. 保存官方图书页面、出版社页面、WorldCat、Google Books、Internet Archive 受控借阅页面等合法访问入口。
3. 对需要付费或机构账号的书籍，建立“待采购或图书馆访问”清单。
4. 对已经合法获得的资料，建立引用索引、章节摘要、事实卡片和短剧选题卡。

不做：

1. 不搜索、下载或保存盗版 PDF、盗版电子书、网盘资源、破解站资源。
2. 不绕过出版社、图书馆或平台的访问限制。
3. 不把受版权保护书籍全文喂给 Agent 做公开分发型内容。

## 获取优先级

1. 官方开放资料：UNESCO、大学开放课程、博物馆、公开考古报告、政府/国际组织出版物。
2. 正版数字访问：Cambridge Core、Oxford Academic、JSTOR、Project MUSE、EBSCO、ProQuest、大学图书馆。
3. 正版纸书/电子书采购：出版社、京东、当当、Amazon、Google Play Books、Apple Books。
4. 合法预览和馆藏入口：Google Books、WorldCat、Internet Archive 受控数字借阅。

## 当前判断

用户提供的 S/A/B 级书单中，大部分 Cambridge、Oxford、Harvard、Routledge、Wiley、Princeton 等出版社图书仍受版权保护，不能直接下载盗版。

其中 UNESCO 系列较适合作为开放资料地基，但需要以 UNESCO 官方页面或合法授权页面为准。当前命令行直接抓取 UNESCO PDF 会返回 403，说明该站点限制脚本下载；后续应优先通过官方页面人工下载，或使用官方允许的下载接口。

## 项目目录建议

- `资料库/开放资料/`：合法开放下载的 PDF、网页导出、报告。
- `资料库/待采购或图书馆访问/`：需要购买、借阅、机构账号的书籍清单。
- `资料库/索引/`：书单、来源链接、访问状态、阅读计划、引用规范。
- `资料库/事实卡片/`：从合法资料中提取的时间、地点、人群、问题、解决方式、文明变化。
